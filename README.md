# PDCS Elevate

You are an expert senior web designer, creative director, and frontend developer.

I want you to build a premium, modern, cinematic website for PDCS (Pty) Ltd, a South African professional cleaning company.

I have provided reference images containing the company’s existing logo/branding and a branded service vehicle. Use these as the source of truth for the brand identity. Do not redesign the logo.

BRAND

Company:

PDCS (Pty) Ltd

Tagline:

YOUR SPACE, OUR STANDARD

Existing services shown in the supplied branding:

* Residential Cleaning

* Commercial Cleaning

* Upholstery & Tile Cleaning

* Window Cleaning

* Post-Construction Cleaning

The company is positioned as a professional, reliable and high-standard cleaning service.

⸻

OVERALL CREATIVE DIRECTION

I want the website to feel:

MODERN + PREMIUM + CINEMATIC + SLIGHTLY FUTURISTIC

Do NOT make it look like a generic cleaning-company website.

Think:

* premium corporate brand

* modern architecture

* luxury service company

* subtle technology-inspired design

* cinematic photography

* extremely clean layouts

* sophisticated animations

* strong typography

* high-end agency-quality design

The website should feel like a company that could eventually service major commercial buildings and corporate clients.

It should NOT feel like:

* a cheap local car wash

* a basic WordPress template

* a generic small-business website

* a childish cleaning website

* an overly futuristic sci-fi website

The futuristic elements must be subtle.

⸻

BRAND COLOURS

Use the existing PDCS branding as the foundation.

Primary:

* Deep navy / midnight blue

* White

Accent:

* Electric/corporate blue taken from the existing logo and vehicle

Use blue strategically rather than covering the entire website in blue.

The website should have plenty of whitespace and dark premium sections.

Use the blue textured/marbled material visible in the existing logo and vehicle as a subtle recurring brand texture.

Do not overuse it.

⸻

TYPOGRAPHY

Use a modern, premium sans-serif typeface.

Typography should have:

* very large hero headings

* strong weight contrast

* clean body text

* generous letter spacing where appropriate

* excellent readability

Headings should feel confident and architectural.

Avoid playful fonts.

⸻

HERO SECTION

This is the most important section.

Create a cinematic hero experience.

The opening should immediately communicate:

PDCS

YOUR SPACE, OUR STANDARD

Use a dark navy/near-black background.

Introduce subtle motion:

* slow-moving light

* soft blue glow

* subtle texture

* elegant particles or dust-like movement

* very subtle grain

* smooth transitions

Do NOT use cheesy particle effects.

The animation should feel expensive.

The hero should eventually reveal a large, high-quality visual related to:

* pristine modern buildings

* professional cleaning

* spotless commercial spaces

* premium residential interiors

Use a cinematic overlay so the text remains readable.

Hero copy:

PROFESSIONAL CLEANING.

WITHOUT COMPROMISE.

Supporting text:

Professional cleaning solutions for residential, commercial and post-construction spaces.

Primary CTA:

REQUEST A QUOTE

Secondary CTA:

OUR SERVICES

Include a subtle animated scroll indicator.

⸻

HERO ANIMATION

Create the hero animation using modern frontend techniques rather than relying on a random stock video.

If no actual video asset is available, create a sophisticated animated hero using:

* CSS

* gradients

* layered imagery

* subtle motion

* parallax

* blur

* light effects

* smooth reveal animations

If a video asset is added later, make the architecture flexible enough to replace the animated background with a real video.

The animation should remain performant.

Respect:

prefers-reduced-motion.

⸻

NAVIGATION

Create a premium sticky navigation bar.

Desktop:

PDCS logo on the left.

Navigation:

* Home

* About

* Services

* Why PDCS

* Contact

Right side:

REQUEST A QUOTE

The navbar should become slightly more opaque/darker when scrolling.

Mobile:

* logo

* hamburger menu

* smooth mobile navigation

Do not make the navbar oversized.

⸻

SERVICES SECTION

Create a visually impressive services section.

Heading:

OUR SERVICES

Supporting line:

Professional cleaning solutions built around your space.

Create five premium service cards.

01 — RESIDENTIAL CLEANING

Professional cleaning services designed to keep homes fresh, hygienic and comfortable.

02 — COMMERCIAL CLEANING

Reliable cleaning solutions for offices, commercial properties and professional environments.

03 — UPHOLSTERY & TILE CLEANING

Deep cleaning for upholstered surfaces, tiles and grout.

04 — WINDOW CLEANING

Professional window cleaning for a clear, polished finish.

05 — POST-CONSTRUCTION CLEANING

Detailed cleaning after construction or renovation, preparing spaces for occupancy.

Each card should have:

* large number

* minimal icon

* title

* short description

* subtle hover animation

* blue accent

* premium border treatment

Do not use generic cartoon cleaning icons.

Use minimal line icons or elegant abstract visual elements.

⸻

CINEMATIC TRANSITION

Between major sections, use cinematic visual transitions.

Examples:

* large typography moving across the screen

* image reveal

* subtle blue light sweep

* masked image transitions

* smooth parallax

Keep everything tasteful.

The website should feel fluid rather than like a collection of separate blocks.

⸻

ABOUT SECTION

Create an About section that communicates professionalism and trust.

Heading:

A HIGHER STANDARD OF CLEAN

Copy should focus on:

* professionalism

* consistency

* attention to detail

* reliability

* quality

Do not invent:

* years of experience

* certifications

* number of employees

* clients

* awards

* locations

* guarantees

Only use facts that are actually provided.

If information is missing, structure the section so it can easily be replaced later.

Use a premium image of a spotless modern space or professional cleaning environment.

⸻

WHY PDCS SECTION

Create a section called:

WHY PDCS

Use four principles:

QUALITY

Attention to detail in every clean.

RELIABILITY

Professional service you can count on.

PRECISION

A methodical approach to every space.

STANDARD

A commitment to maintaining a higher standard.

Use subtle animated numbers or visual markers.

⸻

PROCESS SECTION

Create a simple 4-step process:

01 — REQUEST

Tell us what your space needs.

02 — ASSESS

We understand the requirements of the job.

03 — CLEAN

Our team delivers a professional clean.

04 — COMPLETE

Your space is left ready for use.

Make this section visually strong but simple.

⸻

QUOTE / LEAD GENERATION SECTION

This is extremely important.

The website is not just supposed to look good.

It needs to generate actual business enquiries.

Create a prominent CTA:

READY FOR A CLEANER STANDARD?

Supporting text:

Tell us what you need and request a quote from PDCS.

Button:

REQUEST A QUOTE

Create a quote form with:

* Name

* Phone number

* Email

* Service required

* Property type

* Message

* Optional photo upload if technically practical

Service dropdown:

* Residential Cleaning

* Commercial Cleaning

* Upholstery & Tile Cleaning

* Window Cleaning

* Post-Construction Cleaning

* Other

Do not invent a phone number or email address.

Use clearly marked placeholders until the real details are supplied.

⸻

WHATSAPP

Because this is a South African business, make WhatsApp an important conversion path.

Create a floating WhatsApp CTA.

Do not invent the number.

Create a configuration variable for the WhatsApp number so the owner can easily insert it later.

Example:

WHATSAPP_NUMBER

The button should say:

CHAT ON WHATSAPP

⸻

CONTACT SECTION

Create a premium contact section.

Include placeholders for:

* Phone

* WhatsApp

* Email

* Service Area

* Business Hours

Do not fabricate any of these details.

Make the structure easy to update once the owner provides them.

⸻

FOOTER

Minimal premium footer.

PDCS logo.

YOUR SPACE, OUR STANDARD

Navigation links.

Services.

Contact.

Social media placeholders.

Copyright:

© 2026 PDCS (Pty) Ltd. All rights reserved.

⸻

VISUAL DETAILS

Use:

* subtle glass effects

* deep shadows

* thin borders

* blue glow accents

* soft gradients

* high-quality imagery

* large typography

* generous spacing

* subtle noise/grain

* elegant hover states

Avoid:

* excessive rounded cards

* excessive gradients

* emoji

* cartoon graphics

* cheap-looking stock photography

* excessive shadows

* giant blobs

* overdone glassmorphism

* unnecessary animations

⸻

ANIMATION SYSTEM

Use a consistent motion language.

Animations should include:

* fade + translate reveals

* staggered service cards

* image clipping/reveals

* smooth hover states

* subtle parallax

* navbar transitions

* button micro-interactions

* page-load hero sequence

Use animation libraries only if genuinely useful.

Prefer performant CSS and lightweight JavaScript where possible.

Do not make every element fly onto the screen.

Motion should communicate precision and quality.

⸻

RESPONSIVENESS

The website must be designed mobile-first.

It must look excellent on:

* iPhone

* Android

* tablet

* laptop

* desktop

* large desktop screens

Pay particular attention to:

* hero typography

* navigation

* CTA buttons

* service cards

* quote form

* image cropping

No horizontal overflow.

⸻

PERFORMANCE

Prioritize:

* fast load times

* optimized images

* lazy loading

* responsive image sizes

* minimal unnecessary dependencies

* smooth scrolling

* good Lighthouse performance

Do not sacrifice performance for unnecessary visual effects.

⸻

SEO

Set up a strong SEO foundation.

Title:

PDCS (Pty) Ltd | Professional Cleaning Services

Meta description:

Professional residential, commercial, upholstery, tile, window and post-construction cleaning services from PDCS (Pty) Ltd.

Use proper:

* semantic HTML

* heading hierarchy

* image alt text

* metadata

* Open Graph metadata

* favicon support

Do not claim specific locations until they are provided.

⸻

ACCESSIBILITY

Follow accessibility best practices.

Include:

* keyboard navigation

* visible focus states

* appropriate contrast

* semantic HTML

* aria labels where required

* reduced motion support

* accessible forms

* meaningful alt text

⸻

TECHNICAL REQUIREMENTS

Before writing code, inspect the existing project structure and determine the framework already being used.

Do not unnecessarily replace the existing stack.

If starting from scratch, use a modern frontend stack appropriate for a high-quality production website.

Keep components modular.

Suggested structure:

* Navbar

* Hero

* Services

* About

* WhyPDCS

* Process

* QuoteForm

* Contact

* Footer

Keep content/data separated where practical so services and company information can easily be updated.

⸻

IMAGE ASSETS

The provided reference images include:

1. PDCS logo

2. PDCS branded Nissan NP200 service vehicle

Use these assets as brand references.

Do not alter the logo.

The branded vehicle can be incorporated into the website as a visual element, particularly in:

* About section

* Brand section

* CTA section

Use professional cleaning/building imagery for the rest of the website.

If image assets are unavailable locally, structure the site with appropriate image placeholders rather than hardcoding random low-quality images.

⸻

IMPORTANT BRAND RULE

The existing PDCS identity must remain recognizable.

Do not redesign the company into a completely different brand.

Instead:

ELEVATE THE EXISTING BRAND.

Take the navy + white + blue identity and turn it into something that feels like a modern premium company.

⸻

FINAL DESIGN TEST

When finished, look at the website and ask:

“If I removed the company name, would this look like a cheap local cleaning website or a serious professional company?”

The answer must be:

A serious professional company.

The website should make someone think:

“These guys take their work seriously.”

Not:

“Someone made this website from a template.”

Build the complete responsive website now.

Do not stop at a wireframe.

Do not use placeholder Lorem Ipsum.

Where real business information has not yet been provided, use clearly labelled editable placeholders rather than inventing facts.
